# sm_trajectory S3 class

An `sm_trajectory` object encodes the career trajectory of a single
author across a corpus, including career stages, topic pivots,
collaborator turnover, emerging collaborators, h-index curve, novelty
curve, and citation acceleration.

The object is created by
[`sm_author_trajectory()`](https://r-heller.github.io/scimapR/reference/sm_author_trajectory.md)
and should not normally be constructed directly.
