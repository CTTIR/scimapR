# Export corpus for Covidence

Write corpus works in RIS format for Covidence import.

## Usage

``` r
sm_export_covidence(corpus, path)
```

## Arguments

- corpus:

  An `sm_corpus`.

- path:

  Output file path.

## Value

`path` invisibly.
