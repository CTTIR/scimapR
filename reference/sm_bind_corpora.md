# Bind two corpora together

Row-bind all tables of two `sm_corpus` objects.

## Usage

``` r
sm_bind_corpora(corpus1, corpus2)
```

## Arguments

- corpus1:

  An `sm_corpus`.

- corpus2:

  An `sm_corpus`.

## Value

An `sm_corpus` object.
