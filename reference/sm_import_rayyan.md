# Import screening decisions from Rayyan

Read Rayyan CSV export and parse screening decisions.

## Usage

``` r
sm_import_rayyan(path)
```

## Arguments

- path:

  Path to Rayyan CSV export.

## Value

A tibble of screening decisions.
