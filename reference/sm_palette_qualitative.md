# Qualitative viridis palette

Qualitative viridis palette

## Usage

``` r
sm_palette_qualitative(n, option = "D")
```

## Arguments

- n:

  Number of colours.

- option:

  Viridis palette option.

## Value

A character vector of hex colours.
