# Plot Lotka's law

Frequency distribution of author productivity compared to Lotka's law.

## Usage

``` r
sm_plot_lotka(corpus, dark = FALSE, ...)
```

## Arguments

- corpus:

  An `sm_corpus`.

- dark:

  Logical; dark mode?

- ...:

  Additional arguments.

## Value

A `ggplot` object.
