# Export corpus for Rayyan

Write corpus works in RIS format for import into Rayyan.

## Usage

``` r
sm_export_rayyan(corpus, path)
```

## Arguments

- corpus:

  An `sm_corpus`.

- path:

  Output file path.

## Value

`path` invisibly.
